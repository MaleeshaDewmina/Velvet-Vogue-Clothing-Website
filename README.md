# Velvet Vogue

A PHP clothing storefront with catalogue filters, product reviews, checkout and an order-management interface.

The customer pages cover browsing clothing, viewing product details and managing a cart. The `admin/` directory contains the product and order management screens. Developed for the HND Web Design and Development module.

**Technologies**  
PHP · MySQL · HTML · CSS · JavaScript

## Run locally

Start with `index.php` for the storefront and `admin/dashboard.php` for the management interface. To run the full site locally, restore the matching MySQL schema and the shared `includes/` files for the connection, navigation and footer. Serve the project root with a PHP-enabled web server and open `index.php`.
